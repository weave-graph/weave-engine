# Authorized navigation graphs

The native `Engine::cluster_navigation` host API builds a graph value from an exact source revision, context, valid-time sample, relation predicate and requested lazy level count. It reads through runtime authorization, retains isolated visible nodes, and selects only positive, applicable relations. It accepts no caller-supplied authorized snapshot or fabricated provenance envelope. It is not yet a language operator or a signed remote admission operation.

The returned graph has source-linked leaf wrappers, cluster records, a manifest, direct-child membership relations and directed existential aggregate relations. Wrappers carry exact source NodeRefs and original entity/space identifiers as descriptive properties; they are navigation objects, not replacement manifestations or accepted identity decisions. Each cluster has its direct children and original source-link evidence IDs. Membership expansion is graph traversal. Generated relations with assertion witnesses carry operator derivations; node-only relations use stable grounded synthetic identity for union/projection/diff. Direct assertion-support or join operators over node-only relations require persistence followed by an authorized read that creates actual stored assertion origins; see [synthetic relation boundaries](SYNTHETIC_RELATIONS.md). Levels are materialized lazily on request; disconnected evidence ends expansion. The implementation recomputes each call and does not persist a mutable hierarchy cache.

All output nodes conservatively depend on every selected source node and assertion because matching decisions and counts can depend on competing adjacency elsewhere in the visible input. Clearing readers, removing edges or saving a node-only aggregate therefore cannot release private source influence. This may hide an entire saved navigation graph from a reader who can see a subset; recompute under that reader to obtain their own navigation graph. The native service permits at most 999 combined source node/assertion influences and reserves one slot for a saved graph's own pin. It also enforces existing shared runtime read and output-byte budgets and the portable hierarchy's work bounds. It does not claim to bound every allocator byte or CPU instruction.

Coverage is always the same scoped `Partial` marker: authorized available evidence is not a global directory. Hidden members do not appear in names, counts or layout. Exact source revision pins and cluster record revisions remain observable and can change after private-only source edits; stable membership IDs and the visible layout use visible membership. This is not timing or activity hiding. Generated relations apply to the discrete half-open sample interval `[valid_at, valid_at+1)` and do not claim applicability beyond the sample. The maximum signed timestamp is rejected because its exclusive end is unrepresentable.

Navigation remains approximate. An aggregate relation means at least one contributing authorized source relation, never all members. Exact queries continue to inspect the original evidence and do not use cluster absence to prune candidates. Tests compare exact source-query results before and after navigation construction, but do not constitute a general recall benchmark.

Six root tests exercise lazy expansion with isolated leaves and direct children, unchanged exact query results, deterministic repeated construction, reader stripping for private isolated-node and relation influence, capsule roundtrip, exact context/time/polarity, missing pins, private-only source changes, resource-limit failures without writes, and self/nested union of connected and isolated navigation values. Full E13 still requires language operators, persistent graph metadata, event-driven incremental maintenance, version-to-version split/merge lineage, hysteresis and measured quality/churn/recall acceptance.
