# Lazy topology clustering foundation

`weave-cluster` provides an I/O-free navigation hierarchy over a **trusted host's already authorized snapshot**. It does not authenticate a caller, resolve graph references, grant visibility, persist results, or execute exact queries. A host must select visible nodes and positive relations, exact context and valid time before invoking it. All returned memberships, labels, counts and source references retain that host's disclosure restrictions. Constructing a `Snapshot` from JSON is not authorization.

The initial algorithm `weave:topology-matching:1` sorts visible adjacency pairs, chooses a deterministic maximal matching and combines each matched pair. One `advance` materializes one level. Unmatched objects remain available. Each successful level strictly reduces the frontier; a level without any connecting relation records the available evidence boundary. Self-links never manufacture additional depth. There is no semantic depth constant. Separate relation perspectives can create overlapping organizations; each individual hierarchy is acyclic. This topology baseline makes no community-quality, Leiden, embedding, hysteresis or global optimality claim.

Clusters are addressable records with direct children, original members, contributing source-link IDs, algorithm level and stable membership identities and separate record revisions. IDs depend on the algorithm, perspective, exact context and visible member IDs. They do not hash an entire underlying graph revision, so a private-only revision does not perturb an otherwise identical authorized layout. A membership ID is not a complete record cache key: different decompositions can share a member set. Each record therefore has a separate digest binding its children, evidence links, level and canonical authorized source snapshot. Consumers must use both ID and revision when caching a record. The source envelope still records the true input pins. Reproducibility is for the same authorized input and version, not a claim of globally identical peer layouts.

`zoom` returns direct members; `evidence` pages through original contributing links. Aggregate directed relations retain every contributing source link and mean **at least one** such relation. The manifest marks navigation approximate, retains partial-input status and distinguishes evidence exhaustion from budget errors. No camera API or approximate exclusion API exists. Exact queries must continue to inspect authorized source evidence or use an independently sound index. The original authorized node, link and proof-reference sets remain accessible; construction only canonicalizes their ordering.

The current host limits are 10,000 nodes, 100,000 links, 16 MiB serialized input, 32 MiB stored cluster records, 256 proof references per input link and 2,000,000 logical matching-work units. Hosts can lower the work limit. These are operation limits, not a bound on all allocator overhead or CPU instructions. Serialization limits use a streaming counter. Matching uses two relation passes per level plus ordered maps, not one full relation scan per new cluster. A failed level leaves the navigation frontier and cluster records unchanged; attempted work remains charged. Evidence pages contain at most 256 IDs.

Seven independent tests cover recursive expansion with a disconnected evidence boundary, exact leaf/evidence preservation, canonical-order reproducibility, unchanged visible layout across private-only source revisions, directed aggregate relation witnesses, overlapping perspectives, malformed provenance and explicit budget/partial behavior. The privacy test assumes the host supplied identical authorized facts; it is not a full runtime noninterference proof.

Still required for E13: native authorized graph-service integration, graph-valued metadata and query operations, version-to-version split/merge lineage, event-driven incremental updates and hysteresis, task-quality/churn measurements, and end-to-end exact-search recall tests. This crate is an experimental foundation, not completion of automatic clustering or semantic zoom delivery.
