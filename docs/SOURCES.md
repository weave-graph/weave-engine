# Source and requirement provenance

The architecture originated in a user discussion proposing a new graph-native language and runtime under the working name Weave. The recovered conversation contains truncated portions, and the two original v0.1 white-paper attachments have not yet been recovered. This repository does not present the conversation as either paper.

The explicit requirements are: multidimensional manifestations of shared entities; joinable temporal parameterized graphs; recursive automatic clustering and zoom; decentralization and graph attachment/detachment; permissions and visibility; optional governance; directional 3D and embedding spaces with bridges; mobile and personal offline branches; a runtime event bus with registered adapters; and graph-valued metadata on both nodes and edges. The user approved public MIT projects named `weave-language` and `weave-engine` in the proposed `weave-graph` organization.

The companion architectural proposals distinguish identity from manifestation, branch from space and replica, valid time from system time, and synchronization from acceptance. They propose pinned graph references, provenance, explicit incomplete coverage, portable capsules, policy propagation and atomic commit/event publication. These proposals are represented in the full implementation plan with source labels.

Original paper reconciliation remains an explicit incomplete gate. The private recovered transcript is intentionally excluded from Git. Public documentation uses synthetic examples and this curated requirements summary.
