# Original architecture sources

These Markdown files and the engine paper’s original PDF and DOCX are unchanged copies of the original v0.1 architecture white papers supplied by the user on 19 September 2026. Both papers are dated 11 September 2026. `manifest.json` records exact byte counts and SHA-256 checksums for provenance.

The papers are architecture proposals, not evidence of an implemented feature or measured capacity. Their illustrative syntax is not a mandatory grammar. Requirements and implementation/research boundaries are reconciled in `../RECONCILIATION.md`.

The private recovered conversation remains excluded from Git and is superseded by these complete sources for architecture reconciliation.

Download the engine paper as [PDF](Weave_Engine_White_Paper_v0.1.pdf), [Word](Weave_Engine_White_Paper_v0.1.docx), or [Markdown](Weave_Engine_White_Paper_v0.1.md).

The language paper is available as [Markdown](Weave_Language_White_Paper_v0.1.md).

The goals Weave pursues now are stated in [VISION.md](../../VISION.md). They narrow and reorder the scope of these papers; the [roadmap](../ROADMAP.md) records which paper requirements are scheduled or deferred.
