# Contract 0.10.0: declared counterpart bridges

`GraphExpression::Counterparts { input, selection }` selects explicit identity-bridge assertions from an already-authorized graph value. `CounterpartSelection` names a predicate, exact entity ID, distinct source and target space IDs, and a valid-time instant. Only positive claims valid at that instant can provide a bridge. The selected directed edge must connect manifestations with exactly the requested shared entity ID and spaces. Semantic similarity, matching names, equal vectors and coordinate transforms never establish this relation.

The graph result retains the original manifestations, local properties, structural edge identity, assertion origin, immutable revision pin, schema and applicable context. It is reusable in existing explicit graph joins, which retain the bridge assertion as a premise. Traversal does not copy state between manifestations or synchronize their properties. Private, unavailable and disconnected membership does not contribute to an asserted global cardinality. Coverage is relative to the authorized supplied graph value.

A contextual bridge requires matching context selection. Unqualified/default claims are not broadcast into other worlds. A negative claim does not create a traversable positive bridge; this operator selects declared positive evidence and does not adjudicate contradictions or certify acceptance. An empty result does not establish universal absence of counterparts.

This is a bounded declared-bridge profile, not the complete identity resolver described in engine §6 and language §2.2. Named acceptance policies, independently created identity candidates, accepted mappings, supersession, splits, protected pairwise identifiers and normalized identity-membership virtual adjacency remain required follow-up work. Selecting a graph and revision is explicit evidence selection; a source attribution label is not authenticated governance acceptance.

The 0.1–0.9 wire profiles remain accepted, but nested Counterparts operators require 0.10. Geometry, Float schemas, derived node proof gates and Explain retain their 0.9 compatibility. Counterpart evaluation is pure and emits no graph revisions or events. Native tests cover historical pins, correction and expiry, local-state independence, hidden membership, negative evidence and atomic old-profile rejection; portable and source tests cover selector validation and graph composition.
