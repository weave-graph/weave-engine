# Contract 0.5: bounded graph algebra and alternative derivations

New pure expressions are `Union {left,right}`, `Diff {before,after}`, `Project {input,node_ids,edge_ids}`, and `Support {input,predicate,from,to,valid_at}`. Prior profiles remain executable. These operators and persisted derivation groups require version 0.5; a caller persisting a newly returned graph uses its result version.

Union preserves independent assertions and deduplicates the same pinned origin/record; it never treats similar names as identity. Runtime-produced `node_origins` bind original graph/revision/node manifestations through composition. Typed operands synthesize a coherent descriptor; mixed typed/untyped operands require explicit mapping. Projection keeps selected edges and their endpoints. Diff records added/removed membership in reserved named literal metadata, preserving assertion polarity. Support reports unknown, supported, refuted or conflicted at a required instant from visible evidence. Missing evidence stays unknown, and partial coverage remains partial. No closed-world negative inference is enabled.

Each edge may persist `derivations`: OR alternatives, each containing AND premises, operator, parameters and selected premise snapshots. The existing `derived_from` and `edge_origins` are flattened compatibility indexes, not Boolean formulas. Stored nonempty groups require a matching flat index and bounded nonempty premises. Authorization resolves each group transitively, withholds unavailable groups and their explanations, and retains a conclusion only when at least one complete visible group exists. Missing alternatives produce generic partial coverage. Join takes a bounded cross product of alternatives; metadata traversal contributes attachment premises and time restrictions. Intermediate operator context remains available in derivation traces.

Origin envelopes are computed by the trusted engine from pinned snapshots. They are not cryptographic signatures, and raw programs cannot supply authoritative `QueryResult` envelopes. This profile still uses the legacy combined structural-edge/assertion record; it does not establish independent corroboration from revision counts. Serialized byte/object limits apply during pure result construction.
